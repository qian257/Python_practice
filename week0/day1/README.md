# Simple Four Arithmetic Calculator
A simple Python calculator supporting + - * / four basic operations.

## Features
1. Receive user input in loop, input format: `number operator number` (e.g. `3 + 5`)
2. Type `q` to exit the program
3. Handle division by zero, prompt message without crash
4. Catch wrong input format and continue running
